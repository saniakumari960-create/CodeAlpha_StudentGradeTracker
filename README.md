# CodeAlpha Student Grade Tracker

## About the Project

Student Grade Tracker is a Java console-based application developed as part of the CodeAlpha Java Programming Internship.

The program allows users to enter student names and marks and generates a summary report.

## Features

- Enter student names
- Enter student marks
- Calculate average marks
- Find highest marks
- Find lowest marks
- Display a student grade report

## Technologies Used

- Java
- Arrays
- Scanner
- Loops
- Conditional Statements
